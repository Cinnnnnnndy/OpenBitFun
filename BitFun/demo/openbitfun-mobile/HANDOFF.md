# OpenBitFun Mobile Demo · 交接文档

## 1. 这是什么

一个**单文件 HTML 移动端 Demo**，用来演示 OpenBitFun 在三种设备形态下的界面：

| 形态 | 说明 |
|---|---|
| 直板机 | 393 × 852，侧栏以抽屉形式覆盖内容 |
| 双折 | 660 × 720，侧栏常驻，可收起/展开 |
| 三折叠 | 1024 × 640（宽度自适应），侧栏常驻，可收起/展开，小应用一行两个 |

## 2. 文件位置

```
仓库: https://github.com/Cinnnnnnndy/OpenBitFun
路径: BitFun/demo/openbitfun-mobile/

├── index.html        # 主 Demo（样式 + 结构 + 脚本全在这一个文件里）
├── assets/           # 图片资源（封面图、Logo SVG）
└── HANDOFF.md        # 本文档
```

## 3. 本地预览

```bash
cd BitFun
python3 -m http.server 8766
# 打开 http://127.0.0.1:8766/demo/openbitfun-mobile/index.html
```

> 注意：不要双击 index.html 直接打开，图片路径需要 HTTP 服务。

## 4. 已完成的改动

### 设备圆角统一
- 三种形态外框/内屏圆角保持 `10px` 差值
  - 直板机：外框 62px / 内屏 52px
  - 双折：外框 48px / 内屏 38px
  - 三折叠：外框 40px / 内屏 30px

### 小应用列表卡片
- 文字左对齐，标题 `18px / 600`，描述 `14px / 400`，间距 `4px`
- 标题 + 描述包在 `.app-text` 里，整体在卡片右侧垂直居中
- 图片铺满左侧，无内边距
- 三折叠一行两个卡片，安全边距 `28px`

### 滑动大卡片
- 与列表卡片统一文字规格：`17px / 600` 标题、`14px / 400` 描述、间距 `4px`

### 侧栏
- 三种形态侧栏宽度统一 `295px`
- 侧栏文字禁止误选（`user-select: none`）
- 收起/展开按钮：展开时显示右竖线面板图标，收起后显示左竖线面板图标
- 双折/三折叠收起侧栏后，悬浮按钮（`#openDrawer`）点击直接恢复常驻侧栏

## 6. 已知注意事项

- 页面里有两处容器查询（`@container app`）会覆盖圆角，改圆角时**两处都要同步**。
- `.app-name` 在文件里出现了两次（列表卡片 + 另一处旧规则），改字号时注意选择器优先级。
- 推送前先 `git fetch openbitfun main && git rebase openbitfun/main`，避免分支分叉。
